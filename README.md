# Property Pal Dashboard

"Build a responsive Admin Dashboard for a real estate AI receptionist. I need a sidebar with 4 tabs connecting directly to my Supabase tables:

Properties: A CRUD data table to manage inventory connected to the properties table. Fields: Name, Type, Status, Location, Price.

Executives: A CRUD table for sales staff connected to the executives table.

Dialect Dictionary: A simple CRUD table where non-technical staff can add new local words to the dialect_dictionary table. Columns: Regional Word, Standard Meaning, Example.

Knowledge Base: A UI to upload text content (company history, FAQs). Include a Title field and a large text area for Content. When saved, this should insert into the company_documents table. Use a clean, modern aesthetic similar to Vercel's dashboard.
